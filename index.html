RACE Image Factory [Capstone]

RMIT University IT Services

July - Nov 2026
Melbourne, Australia

For my capstone, I built the RACE Image Factory for RMIT IT Services: an automated pipeline that creates secure, ready-to-use AWS machine images (AMIs) for researchers. A GitHub Actions workflow signs in to AWS using OIDC (no stored passwords), then Packer and Ansible build the RHEL image. I added hash-based change detection: the pipeline creates a hash of the Packer and Ansible files, detects when something has changed, and automatically rebuilds the image. I wrote the infrastructure in Terraform (IAM, S3, KMS, CloudWatch, DynamoDB) following the team's tagging standards, and saved build history in DynamoDB. I also moved legacy EC2 Image Builder steps into Ansible, and designed a React + TypeScript web page so non-technical users can start a build without using GitHub. I worked in sprints with the ITS team and fixed real pipeline issues such as access errors and build timeouts.
AWS Packer Ansible Terraform GitHub Actions OIDC DynamoDB IAM Auto Rebuild React TypeScript Agile / Sprints
